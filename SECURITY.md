# Security

Write to [legal@orgasm.dev](mailto:legal@orgasm.dev) to report a vulnerability in this SDK, or a check it should make before it sends a frame and does not. Please do not open a public issue for it. Say which version and platform, and how to reproduce it.

What the SDK checks, and where in the source, is in the README ("What it checks before a frame leaves the device"). A finding in the enclave the SDK verifies belongs to [the enclave's source](https://github.com/Masseuse-ai/masseuse-video-tee), whose own `SECURITY.md` says where to report it.
